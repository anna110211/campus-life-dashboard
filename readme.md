# 🎓 캠퍼스 생활 설문 결과 대시보드

이 프로젝트는 대학교 학생들의 '캠퍼스 생활 만족도 및 생활 습관' 설문조사 결과를 시각화하고 분석하는 인터랙티브 웹 대시보드입니다. Python과 Streamlit을 기반으로 제작되었습니다.

## ✨ 주요 기능
- **데이터 업로드 및 전처리**: CSV 파일을 업로드하면 결측치와 이상치를 자동으로 필터링하고 요약 정보를 제공합니다.
- **학과별 맞춤 필터링**: 드롭다운을 통해 특정 학과를 선택하면 모든 차트와 지표가 실시간으로 업데이트됩니다.
- **다차원 데이터 시각화**:
  - 📊 **막대그래프**: 학과별 공부/수면/스마트폰 사용 시간 비교
  - 🔥 **히트맵**: 생활 습관과 학교생활 만족도 간의 상관관계 분석
  - ☁️ **워드클라우드**: 학생들의 주관식 한 줄 의견 키워드 시각화
  - 💡 **심층 텍스트 분석**: 한 줄 의견 내 자주 등장하는 Top 10 단어 및 긍정/부정 단어 빈도 분석

## 🛠️ 설치 및 실행 방법

**1. 필수 라이브러리 설치**
터미널(또는 명령 프롬프트)을 열고 아래 명령어를 입력하여 필요한 파이썬 패키지를 설치합니다.
```bash
pip install -r requirements.txt
```

**2. 필요 파일 준비**
실행할 파이썬 스크립트(`app.py`)가 있는 폴더에 다음 파일들이 함께 있는지 확인하세요.
- `campus_life.csv` (설문조사 원본 데이터)
- `NanumGothic.ttf` (한글 깨짐 방지를 위한 폰트 파일)

**3. 앱 실행**
아래 명령어를 통해 Streamlit 서버를 실행합니다.
```bash
streamlit run app.py
```
명령어를 실행하면 웹 브라우저가 열리며 대시보드 화면을 확인할 수 있습니다.

## 📝 데이터(CSV) 포맷 안내
업로드하는 CSV 파일은 다음의 컬럼명(또는 유사한 키워드를 포함한 컬럼명)을 포함해야 정상적으로 작동합니다.
- 학과 (또는 전공)
- 만족도 (또는 학교생활만족도)
- 공부시간
- 수면시간
- 스마트폰 사용시간
- 한줄의견 (또는 의견)
